# Ассеты umakovshop.com (выгрузка для нового сайта)

Дата выгрузки: 2026-08-27. Источник: https://umakovshop.com (Shopify).

## Структура

```
assets/
├── products/<handle>/        — все фото товара, в порядке галереи (01.jpg, 02.jpg, …)
├── collections/<handle>.jpg  — обложка коллекции (категории)
├── brand/                    — логотип, фавикон и прочие элементы бренда
└── _meta/
    ├── catalog.json          — метаданные всех товаров
    └── collections.json      — список коллекций
```

`<handle>` — это URL-слаг товара/коллекции на старом сайте
(например `10-15-adjustable-rear-leg-sol-arl-1015-en`).
Папка товара соответствует адресу `https://umakovshop.com/products/<handle>`.

## _meta/catalog.json

Массив товаров, у каждого:

- `handle`, `title`, `type` (категория Shopify), `tags`
- `price_min_cents` / `price_max_cents` — цены **в центах** (EUR): 656 = €6.56
- `options` и `variants` (название, SKU, цена, доступность)
- `description_html` — описание товара (HTML)
- `images[]` — относительный путь к локальному файлу + исходный URL на CDN
- `url` — страница товара на старом сайте

Этот файл — источник данных для наполнения нового каталога (Medusa):
можно заводить товары вручную, сверяясь с ним, или написать скрипт импорта
через Medusa Admin API, читающий catalog.json и загружающий фото из products/.

## Примечания

- Изображения скачаны в оригинальном (максимальном) разрешении с CDN Shopify.
- Товары, отдавшие 404 при выгрузке, перечислены в логе выгрузки (если такие были).
- Порядок файлов 01, 02, … повторяет порядок галереи на старом сайте.
